# Smart Investor - Professional Design System

## 1. Color Strategy (Dual Theme)
- **Dark Mode (Default):** BG: `#071120`; Surfaces: `#0E1836`.
- **Light Mode:** BG: `#F4F7FA`; Surfaces: `#FFFFFF` (10% shadow elevation).
- **Accents:** Premium Purple (`#7C3AED`); Success Green (`#16C784`); Danger Red (`#EA3943`).

## 2. Professional Loading & States
- **Loading:** Use **Glass Shimmer** skeleton screens for lists. The **AI Advisor** must show the "AI Orb" in a high-energy pulse animation while thinking.
- **Error States:** Use "Professional Alert Cards" with a soft-red glow and a "Smart Retry" button.
- **Success States:** Trigger a "Celebration Glow" (soft green radial bloom) and a "Premium Confirmation Card" with a haptic button press.

## 3. Micro-Interactions & Brand Identity
- **Splash Screen:** Logo must scale from 0.8 to 1.0 with a "Glow Bloom" effect upon entry.
- **Button Press:** Subtle `0.98x` scale down + Haptic feedback.
- **Swipe Actions:** Smooth Z-axis "Card Slide" for Watchlist removal.
- **Recommendation Reveal:** Use a "Fade + Slide Up" transition for AI insights.

## 4. Components & 3D Depth
- **Dashboard 3D Graph:** Hero feature. Interactive tilt and rotation are mandatory.
- **KYC Verification:** Feature a "Glowing Shield" 3D icon that locks when verified.
- **Notifications:** Use "Priority Badges" (Purple for AI, Green for Profits, Blue for News).

## 5. Accessibility & Contrast
- **Typography:** Inter. Financial balances must be `ExtraBold`.
- **Contrast:** Maintain AA standards. Use Color-Safe indicators (icons + colors) for P&L.
